# Vel Tech University Website Clone

This is a clone of the Vel Tech University website created for educational purposes.

## Project Structure

```
veltech_clone/
├── index.html          # Main HTML file
├── styles.css          # CSS styles
├── script.js           # JavaScript functionality
└── images/            # Directory for website images
    ├── veltech-logo.png
    ├── campus-1.jpg
    └── news-1.jpg
```

## Required Images

To complete the website, you'll need to add the following images to the `images` directory:

1. `veltech-logo.png` - The Vel Tech University logo
2. `campus-1.jpg` - Main campus image for the hero section
3. `news-1.jpg` - Image for news section

## Setup Instructions

1. Clone or download this repository
2. Add the required images to the `images` directory
3. Open `index.html` in a web browser to view the website

## Accessing on Mobile Devices

To access the website on your mobile device:

1. Make sure your computer and mobile device are on the same WiFi network
2. Double-click the `start_server.bat` file in the project folder
3. Note the IPv4 address shown in the command prompt
4. On your mobile device:
   - Open Chrome browser
   - Enter the address: `http://YOUR_IP_ADDRESS:8000`
   - Replace YOUR_IP_ADDRESS with the IPv4 address from step 3
   - Allow microphone access when prompted

### Troubleshooting Mobile Access

If you can't access the website on mobile:
1. Check that both devices are on the same WiFi network
2. Make sure no firewall is blocking port 8000
3. Try using the local network IP address (usually starts with 192.168 or 10.0)
4. Ensure Chrome is used on mobile for best compatibility

### Voice Assistant on Mobile

For the voice assistant to work on mobile:
1. Use Chrome browser (voice recognition works best on Chrome)
2. Allow microphone access when prompted
3. Tap the microphone button to start speaking
4. Speak clearly and wait for the response
